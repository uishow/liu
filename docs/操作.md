# 开盘操作手册

网页只负责告诉你这一刻买、卖，还是不动。委托在你自己的券商软件里下。页面不会登录账户，也不会替你报单。

下面按一天的顺序写。你这台 Mac 已经装好依赖，端口用 **8081**。

## 先记住四件事

1. 只看页面最上面那张大卡片。表格是行情参考，卡片才是指令。
2. 卡片上的数量按纸面账户 100 万元计算，一笔大约 10 万元。你的真实资金如果不是 100 万，按比例缩小，并且向下取整到 100 份。算法：`你的数量 = 卡片数量 × 你的可用资金 ÷ 1000000`，结果再去掉末尾不够 100 的零头。溢价 0.5%–1.5% 时，卡片已经是半仓，按这个公式缩放即可。
3. 同一时间只做卡片上的这一只。不要自己再挑表里的另一只。
4. 一天最多 3 笔。连续亏 2 笔，卡片会写成停止交易，当天收手。14:45 前必须卖掉，不留隔夜。

## 开盘前：把页面打开

9:15 前打开「终端」，执行：

```bash
cd "/Users/beryllewis/private/stock/grok/ETF t+0/liu"
git pull
source .venv/bin/activate
python -m uvicorn app.main:app --host 127.0.0.1 --port 8081
```

看到 `Uvicorn running on http://127.0.0.1:8081` 后，不要关这个窗口。浏览器打开：

```text
http://127.0.0.1:8081
```

第一次要等 20 到 40 秒。就绪的标志是同时满足这三条：

- 四个数字卡片已经出来
- 右上角 eltdx、axdata、IOPV 都是「已连接」
- 页脚出现「行情自动更新」和当前时间，并且这个时间每十几秒会变

时间停住超过一分钟，或某一盏灯变成「中断」，回到终端按 `Ctrl+C`，再执行一次启动命令。

「立即刷新」可以不点。行情、溢价和买卖指导都会自己变。

## 页面上每一块是什么

最上面四个数字是过去三个月的纸面回放，不是你今天的账户盈亏。今天怎么做，看它下面那张大卡片。

大卡片只有四种标题：

| 标题 | 你要做的事 |
| --- | --- |
| 现在买入 | 马上到券商挂限价买单，价格、数量用卡片上的数字 |
| 现在卖出 | 马上把这只卖掉 |
| 持有，先别动 | 仓还在。不补仓，不改单，等它变成「现在卖出」 |
| 现在不交易 或 先不要买 | 什么单都不下。先读标题下面那句原因 |

买入卡片上有四个格子：买入限价、止盈价、止损价、数量。下面几行是按顺序做的步骤。

再往下是「监控」表，用来核对，不用来自己挑股票：

- 最新：现在的成交价
- eltdx / AxData：两路行情。偏离接近 0，说明两边一致
- IOPV：参考净值
- 溢价：价格比净值贵多少。高于 1.5% 不买；0.5% 到 1.5% 卡片会自动把数量减半
- 买一 / 卖一：盘口。价差过大时卡片会禁止买入
- 今日信号：今天曾经出现过的形态，可能已经过期
- 闸门：低于 2 元显示「观望」。恒生科技、恒生互联网这类低价 ETF 经常在这里，看到观望就不要买

「回测」是历史纸面成绩。「方案」是规则说明。盘中不用来回切，盯着大卡片。

## 9:30–10:10：只看，不下单

开盘前 15 分钟和 10:10 之前，卡片应是「现在不交易」。这时做三件核对，不要下单：

1. 看溢价。高于 1.5% 的，今天心里先排除。
2. 看闸门。写着「观望」的，今天排除。
3. 看开盘相对昨收有没有跳空超过 1%。跳空那么大的，这只今天不做。程序会自己拦住，你不用手算，但不要因为跳空上涨去追。

9:45 之前波动大，规则禁止新开仓。

## 10:10–11:15：上午只做这一段

把券商软件和这个网页并排放着。眼睛只看大卡片标题。

### 卡片变成「现在买入」

立刻按这个顺序做，不要先看别的股票：

1. 读标题里的代码和名称，到券商里搜这只 ETF。
2. 选择买入，委托类型选 **限价**，不要选市价，不要选对手价。
3. 价格填「买入限价」那一格，一个字都不要改高。
4. 数量填卡片上的数量。资金不是 100 万时，先用上面的公式换算，再向下取整到 100 份。换算后不足 100 份，这笔不做。
5. 提交。确认委托状态是「已报」，不是「废单」。
6. 看卡片上的有效时间，一般是信号之后 5 分钟，例如写到 10:40。到点还没成交，立刻撤单。撤完就结束，不要改成更高的价格再买。
7. 成交了，马上再挂两笔卖出保护：一笔限价卖出，价格填「止盈价」，数量是全部成交数量；止损价记在纸上或券商条件单里。你的券商如果没有条件单，就盯着网页，等标题变成「现在卖出」再卖。
8. 同一时刻只有这一张单。成交之前不要再买第二只。

### 卡片是「持有，先别动」

说明上一笔已经成交，价格还在止盈和止损中间。

- 不要加仓
- 不要把止盈价改高
- 不要因为下跌把止损取消
- 网页标题变成「现在卖出」之前，卖单只保留止盈那一笔

### 卡片变成「现在卖出」

按原因处理，数量是全部持仓，不要留一半：

- 原因是到达止盈价：卖出用限价，价格就填止盈价。若已经成交在止盈单上，不用再卖一次。
- 原因是到达止损价，或已经 14:45：用买一价或对手价马上卖出，目的是成交，不再等反弹。
- 卖完看券商里这只可用数量变成 0。

### 卡片是「现在不交易」或「先不要买」

读下面那一句，然后什么都不做。常见原因：

- 还没到 10:10，或已经过了 11:15
- 这一根没有新的买点
- 溢价超过 1.5%
- 没有 IOPV
- 买卖价差太大
- 价格低于 2 元
- 开盘跳空达到 1%
- 今天已经做满 3 笔
- 今天已经连亏 2 笔
- 上一张限价单过了有效时间，不要追

表里「今日信号」即使写着 10:35 突破，只要大卡片不是「现在买入」，那张信号就作废了。

## 11:30–13:30：午休

页面开着，终端开着。上午有持仓就留着止盈单，人可以离开，但 13:40 前回到屏幕前。午休不会出现新的买入。

## 13:40–14:15：下午只做这一段

做法和上午完全一样。仍然只听大卡片的。一天的 3 笔是上午加下午一起算，不是各 3 笔。

## 14:15–14:45：只处理卖出

14:15 之后卡片不应该再叫你新开仓。若还持有：

- 14:45 之前，标题变成「现在卖出」
- 到点就用买一价把剩余数量全部卖掉
- 卖掉后看券商持仓，这 10 只里当天买入的数量为 0

14:40 之后不要因为尾盘拉升自己新开一笔。

## 15:00 之后

可以看「回测」里今天多出来的纸面成交，对照自己实际下的单。对不上的常见情况：你追价了、没撤过期单、数量没按比例换算、或者页面有一盏灯当时是中断的。

看完在终端按 `Ctrl+C` 停掉程序。第二天从「开盘前」再做一遍。

## 和券商软件对着填的例子

卡片如果写成：

- 现在买入 · 华安黄金ETF 518880
- 买入限价 8.560
- 止盈价 8.590
- 止损价 8.545
- 数量 11600
- 有效到 10:40

那么在券商里就是：买入，限价，代码 518880，价格 8.560，数量 11600（资金不是 100 万就先换算）。10:40 未成交则撤单。成交后卖出限价 8.590，数量等于成交数量；价格跌到 8.545 或网页写成「现在卖出」时，把剩余的卖掉。

## 盘中出问题

| 你看到的 | 怎么处理 |
| --- | --- |
| 页脚时间不动 | 终端里 `Ctrl+C`，再执行一次启动命令，浏览器重新打开 8081 |
| 右上角有一盏「中断」 | 先不要新开仓。eltdx 约 12000ms、axdata 约 8000ms 是通达信 7709 超时。先 `git pull` 再重启；更新后超时放宽到 20 秒，并且 AxData 会复用同一条连接。IOPV 亮着只说明腾讯网页行情通了 |
| 卡片一直是「还没有 IOPV」 | 同上，溢价不清楚时不买 |
| 8081 打不开，提示地址已被占用 | 启动命令最后改成 `--port 8082`，浏览器也改成 8082 |
| 想更新到最新程序 | 先 `Ctrl+C`，再 `git pull`，然后重新启动 |
