# 本地运行

网页在本机运行。浏览器打开的是你自己电脑上的地址，纸面账户和回测也在本机计算。eltdx、AxData 会从本机出去取行情，所以本机需要能访问通达信行情主站和腾讯行情。

程序不登录券商，也不发送委托。

## 1. 准备环境

- 操作系统：Windows、macOS 或 Linux
- Python 3.12。macOS 上的 `python3` 如果是 3.14，不要用它建虚拟环境。执行 `python3 --version` 确认；若是 3.14，先 `brew install python@3.12`，后面全部改用 `python3.12`
- 能访问外网。首次启动会连接通达信 7709 主站，并请求腾讯行情以读取 IOPV

拿到代码后进入项目目录。目录里应能看到 `app`、`docs`、`requirements.txt`。

```bash
git clone https://github.com/uishow/liu.git
cd liu
git checkout cursor/etf-t0-desk-6e05
```

已经在该目录里工作时，跳过克隆，直接在项目根目录继续。

## 2. 建立虚拟环境并安装依赖

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

如果 PowerShell 禁止执行脚本，先在当前窗口执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

然后再执行上面的 `Activate.ps1`。也可以不激活脚本，改用：

```powershell
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

macOS 或 Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -r requirements.txt
```

安装内容是本机网页所需的 FastAPI、Uvicorn，以及行情库 eltdx、AxData。不需要单独安装通达信客户端。

## 3. 先跑测试（可选）

这一步不连行情，只检查规则本身。

Windows：

```powershell
python -m pytest tests/test_strategy.py
```

macOS 或 Linux 把 `python` 换成 `python3`。5 项测试都通过后再启动网页。

## 4. 启动网页

在项目根目录执行，保持这个窗口不要关。

Windows：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

macOS 或 Linux：

```bash
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

看到类似下面的输出后，服务已经在本机监听：

```text
Uvicorn running on http://127.0.0.1:8080
```

只在自己这台电脑上看页面时，使用 `127.0.0.1`。同一局域网里的另一台设备要访问时，把地址改成 `--host 0.0.0.0`，再用这台电脑的局域网 IP 加端口 8080 打开。

## 5. 打开页面

浏览器访问：

```text
http://127.0.0.1:8080
```

首次打开会先显示“正在连接 eltdx 与 AxData”。程序在后台做三件事：

1. 用 eltdx 拉取 10 只 ETF 各 4 页 5 分钟线
2. 用这些 K 线跑纸面回放
3. 再取 eltdx 五档、AxData 快照和 IOPV

网络正常时大约 20 到 40 秒。出现四个数字后即就绪：

- 样本净利约为 +2,137
- 收益率约为 0.21%
- 胜率约为 56.9%
- 右上角 eltdx、axdata、IOPV 都显示已连接

页顶时间是行情刷新时间。交易时段显示“已收盘”或“开市”，取决于当时是不是 A 股连续竞价。

## 6. 页面上做什么

页首是买卖指导。出现「现在买入」时，按上面的代码、限价、数量到券商挂单，并照止盈价、止损价设好卖出；有效时间过了还没成交就撤。出现「现在卖出」就按对手价卖掉。出现「持有，先别动」就等到止盈、止损或 14:45。出现「现在不交易」就继续看，不要手痒。

监控：十只 ETF 的最新价、eltdx 与 AxData 两边的价格、IOPV、溢价、买一卖一。最新价低于 2 元的标的显示“观望”，例如恒生科技。高于 2 元且溢价、价差都合格的显示“价位合格”。

回测：纸面权益曲线、分月盈亏、分标的盈亏、逐笔成交。样本区间写在曲线说明里。

方案：止盈 0.35%、止损 0.18%，以及两路行情的说明。

页面自己更新。最新价、溢价、买一卖一每 15 秒向 eltdx 和 AxData 重取一次，浏览器每 5 秒刷新显示。交易日 9:25–15:10，大约每 45 秒补一次最新 5 分钟线，并重算今日信号和纸面回放。不用点按钮，也不用为了新 K 线重启。

「立即刷新」只是马上再取一次。页脚时间在走，就说明自动更新还在跑。

## 7. 停止

回到运行 uvicorn 的窗口，按 `Ctrl+C`。

下次还要看，重新执行第 4 步，再打开同一个地址。虚拟环境若已关闭，先按第 2 步激活。

## 8. 数据落在哪里

成功拉取的 5 分钟线写在 `data/cache/m5.json`。这个文件被 git 忽略，只留在本机。下次如果通达信暂时连不上，而这个缓存还在，页面会改用缓存完成回放，来源一栏会写明“缓存”。实时五档和 IOPV 仍然要当场请求，缓存替代不了它们。

## 9. 打不开时看这里

| 现象 | 处理 |
| --- | --- |
| 浏览器一直停在“正在连接” | 看 uvicorn 窗口。首次拉取常要半分钟。超过两分钟仍无四个数字，确认本机能访问外网后重启命令 |
| 页上出现“行情没有连上” | 多半是通达信主站或本机网络被拦住。同一命令再启动一次。若已有 `data/cache/m5.json`，回放仍可出来，但实时三盏灯可能是中断 |
| 端口被占用 | 换端口：`--port 8081`，浏览器改为 `http://127.0.0.1:8081` |
| `python` 找不到 | Windows 用安装时勾选的 Python Launcher：`py -3.12`。macOS / Linux 用 `python3.12` |
| `No matching distribution found for fastapi` | 虚拟环境是 Python 3.14，或 pip 走了没有返回安装包的镜像。删掉 `.venv`，用 `python3.12 -m venv .venv` 重建，再执行 `pip install -r requirements.txt -i https://pypi.org/simple` |
| 依赖安装失败 | 确认虚拟环境已激活，并且 `python --version` 是 3.12，再执行安装 |
| 右上角某一盏是中断 | 等下一次自动更新。eltdx 中断影响五档，axdata 中断影响归一化快照，IOPV 中断影响溢价。页脚时间停止不动时，再执行一次启动命令 |

规则和样本成绩见 [strategy-v2.md](strategy-v2.md)。
